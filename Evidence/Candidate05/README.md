# Candidate05 evidence

This directory currently contains source/import provenance and initial functional
measurements. Rendered captures, moving review, native input, audio quality,
performance and public-package verification are separate claims.

- [Art/audio provenance](ArtAndAudioProvenance.json): authored inputs and source identity.
- [UI import](UIImport.json): nine original HUD textures with actual assembled weapon renders.
- [Audio import](AudioImport.json): 48 original sound assets.
- [Weapon timing](WeaponTiming.md): actual six-variant functional runs at three requested frame caps.
- [Functional integration](FunctionalIntegration.json): initial results and raw report hashes; elevated-target aim coverage is explicitly superseded.
- [Preservation](Preservation.json): pre-publication checks of prior candidate files and refs.
- [Visual review](VisualReview.md): bounded consecutive-frame motion and full-size UI observations, with source scope and remaining limitations.

Private engine logs and raw regenerable captures remain outside source history.
The [pass report](../../Docs/Passes/Candidate05.md) records failed attempts and
pending gates. Final curated evidence will bind each result to its tested source
and keep the packaged source separate from later documentation.
