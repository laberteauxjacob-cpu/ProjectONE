# Project ONE asset provenance

This milestone was authored as a new Project ONE project. Its character meshes, rigs, animation, environment meshes, firearm, blood mask and candidate audio were created specifically for ONE. No Project Zero assets or third-party character, animation, environment, firearm, texture or audio packs were reused. Blender and Unreal Engine supply authoring tools and engine infrastructure; those tools are distinct from the original project assets described below.

| Asset group | Editable source and generation |
| --- | --- |
| Response operator and infected | `ArtSource/Characters/Response.blend`, `Infected.blend` and `CharacterWorkshop.blend`; generated with `Scripts/create_characters.py` in Blender 5.1.2. Original modeled geometry, rigs, skin weights, vertex paint and baked actions are retained. `materials.json` and `manifest.json` record palette and mesh/animation details. |
| Facility and carbine | `ArtSource/Environment/ProjectONE_IndustrialKit.blend`, authored with `Scripts/create_environment.py`. The original modular facility kit includes detailed doors, consoles, benches, racks, vessels, floor markings and the grip-centered carbine. `ArtSource/Environment/manifest.json` records the kit. |
| Blood mask | `ArtSource/Textures/T_BloodMask.png`, generated mathematically in `Scripts/create_environment.py` using an irregular pool and asymmetric droplets with deterministic seed 1707. It contains no sampled or downloaded imagery. Native blood materials are assembled by the importer. |
| Candidate sound design | `ArtSource/Audio/S_CarbineShot.wav`, `S_Reload.wav`, `S_Empty.wav` and `S_Impact.wav`, generated by `Scripts/create_audio.py` using original impulse/noise synthesis and impact sequences. These are provisional synthesized sounds, not recordings and **not approved final realistic weapon audio**. Their artistic realism remains unresolved. |

`ArtSource/Exports/` initially contained the Candidate01 FBX interchange files: four skeletal meshes, fifteen animation clips, two optional static detached-part meshes and thirteen environment/firearm meshes. `Scripts/import_assets.py` creates Unreal assets and native palette/vertex-color materials under `Content/ONE/`; `Scripts/import_character_refinement.py` applies the final targeted garment imports. `Scripts/create_map.py` assembles `/Game/ONE/Maps/Containment` from the original kit. Further authoring and coordinate details are recorded in `Docs/CharacterPipeline.md` and `Docs/EnvironmentPipeline.md`.

The read-only `Scripts/Audit-SourceSync.ps1` audit compared source MD5 values against Unreal's serialized import metadata. `Evidence/final_source_sync.json`, recorded at 2026-09-05 04:46:45 UTC, confirms all 39 imported source files matched: 34 FBX files, one PNG and four WAV files. This establishes source correspondence; it does not constitute artistic acceptance. The assets remain an editable first-milestone candidate requiring further visual and audio refinement.

## Candidate02 additions

The accepted Project ONE assets remain the foundation. `Scripts/create_candidate02_weapon_assets.py` creates five original static meshes, eight Response clips and one Infected heavy-hit clip, with 25 new authored PCM event sounds. The carbine body/magazine split derives from the accepted Project ONE carbine. The pump shotgun, fore-end and shell are newly modeled for this pass. The existing 22-bone rigs are retained. No external audio source, purchased sound pack or Project Zero file was used.

`ArtSource/Weapons/Candidate02/inventory.json` maps every new asset to its source, skeleton, duration, event timing, material and runtime binding. Its neighboring Blender workshops and preview images retain editable source. `Scripts/import_candidate02_weapon_assets.py` imports only the listed additions and three new materials. The 25 WAVs are original layered noise, transient and mechanical synthesis with measured headroom; they are not field recordings. Gameplay output was captured and measured, but perceptual audition was unavailable in this tool session, so realism and mix acceptance remain provisional.

Before public publication, private author paths in FBX headers, Blender workspace metadata and PNG text chunks were sanitized without changing geometry, animation or image pixels. Twelve old Unreal import records were refreshed to match those metadata-only FBX changes. The current [source/import audit](../Evidence/Candidate02/source_sync.json) verifies all 78 source hashes: the original 39 plus 14 new FBX files and 25 WAVs. Candidate01's old evidence remains historical.

Engine-provided runtime code, fonts and libraries are separate from the original game assets. The Windows release retains its packaged notices and includes Unreal's third-party notice catalog as described in [DistributionNotice](DistributionNotice.md). No Unreal Engine source or authoring tools are uploaded in the project repository or playable archive. No broad license for the original game code or art was selected.
