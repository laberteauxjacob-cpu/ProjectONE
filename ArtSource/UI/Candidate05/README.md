# Original Candidate05 HUD artwork

`UI05_Numerals.svg` and `UI05_Glyphs.svg` are editable, original vector path sheets. `Scripts/create_candidate05_ui.py` rasterizes those authored paths with Pillow into the numeric atlas, a complete printable ASCII atlas and a rounded panel mask. It reads no installed or third-party font. Lowercase uses a smaller baseline-aligned version of the same alphabet. DEL and unsupported Unicode intentionally use the question-mark fallback; current HUD strings use printable ASCII.

The six weapon images come from the actual assembled Project ONE weapon objects and their original materials in `ArtSource/Weapons/Candidate04/WeaponWorkshop.blend`. `Scripts/create_candidate05_weapon_icons.py` appends the manifest's body, magazine, slide and fore-end objects as applicable, retaining their common grip origin. A transparent, fixed-camera render produces each icon. It does not trace an unrelated silhouette or modify the accepted source workshop. `WeaponIconStudio.blend` preserves the derived camera/lighting setup and the six assemblies.

Run the UI generator with Python 3 and Pillow. Run the icon generator in Blender 5.1 background mode. Before publication, run `Scripts/sanitize_asset_metadata.py` on the six rendered PNGs and `WeaponIconStudio.blend`; it removes only verified text/path metadata and preserves pixels/scene data. Then pass that exact seven-file report to `py -3 Scripts/audit_candidate05_ui.py --metadata-report <Saved report path>` to reconcile proven metadata changes. `py -3 Scripts/audit_candidate05_ui.py` checks the finalized inventory without changing it. No sanitization dependency is downloaded automatically.

Root-scheduled `Scripts/import_candidate05_ui.py` imports exactly nine textures into `/Game/ONE/UI/Candidate05`, with UI compression, no mipmaps and no streaming. The two inventories bind source hashes, atlas dimensions and actual weapon assembly parts. The runtime Canvas layout uses separate atlas advances and measurement for wrapping; it has no inherited minimum-font-scale clamp. The original HUD combined padded numeric strings with fixed rows and a minimum scale clamp; this was an actual packing defect. The earlier missing-glyph cause was not established, so this artwork change is not described as a capture correction.

Source inspection covered both atlases and all six weapon PNGs. It established legible authored glyph forms, distinct actual weapon families/variants and intact assembled parts. Source inspection alone does not establish packaged layout, mouse routing or visual approval. Those require the separately recorded runtime checks.
